# 🌿 Smart Campus Planner

대학원생을 위한 올인원 할 일 관리 웹앱입니다.
BK 사업, 랩실(수업), 프로젝트, 스터디, 개인 일정을 한 화면에서 등록하고,
목록과 캘린더로 한눈에 확인할 수 있습니다.

별도의 설치나 회원가입 없이, `index.html` 파일을 더블클릭하기만 하면 바로 실행됩니다.

---

## 📌 프로젝트 소개

대학원생은 하루에도 여러 종류의 할 일을 동시에 관리해야 합니다.

- BK 사업단 관련 행정 업무
- 랩실 수업, 세미나, 랩미팅
- 참여 중인 연구/개발 프로젝트
- 스터디 모임
- 그 외 개인적인 할 일

이렇게 성격이 다른 일들이 한 곳에 정리되어 있지 않으면, 마감일을 놓치거나
무엇을 먼저 해야 할지 파악하기 어려워집니다.

**Smart Campus Planner**는 이 다섯 가지 카테고리를 기준으로 할 일을 등록하고,
중요도와 마감일 기준으로 우선순위를 파악하며, 목록 보기와 한 달 캘린더 보기를
자유롭게 오가며 전체 일정을 관리할 수 있도록 만든 개인용 일정 관리 웹앱입니다.

## 🎯 만든 목적

- 대학원생의 실제 활동 구조(BK/랩실/프로젝트/스터디/개인)에 맞춘 카테고리로
  범용 To-Do 앱보다 더 직관적으로 할 일을 분류할 수 있게 하기 위해
- 할 일과 일정을 따로 관리하지 않고, 목록과 캘린더를 오가며 한 번에 확인할 수 있게 하기 위해
- 회원가입이나 로그인 없이, 브라우저만 있으면 누구나 바로 사용할 수 있는
  가볍고 빠른 도구를 만들기 위해
- 새로고침하거나 브라우저를 다시 열어도 입력한 데이터가 사라지지 않도록 하기 위해

자세한 요구사항은 [`PRD.md`](./PRD.md) 문서에서 확인할 수 있습니다.

## ✨ 주요 기능

### 할 일 관리
- ✅ 할 일 추가 (제목 / 카테고리 / 중요도 / 시작일 / 마감일)
- ✏️ 할 일 수정 (기존 입력 폼을 그대로 이용해 수정, 완료 상태는 그대로 유지)
- ☑️ 완료 체크 및 체크 해제
- 🗑️ 할 일 삭제
- 📅 시작일은 선택사항, 마감일은 필수 입력값
  (시작일 없이 마감일만으로도 등록 가능)
- 🏷️ 중요도(상/중/하)는 선택사항이며, 선택하지 않으면 배지가 표시되지 않아 목록이 깔끔하게 유지됨

### 한눈에 보는 현황
- 📊 전체 완료율(%) 및 진행률 막대 자동 계산 (완료/추가/삭제 시 즉시 갱신)
- 📅 오늘 할 일 개수, 이번 주 마감 개수, 기한 지난 할 일 개수를 보여주는 상단 요약 대시보드
- ⏳ 각 할 일의 마감일 기준 D-Day 자동 표시 (`D-5`, `D-1`, `D-Day`, `D+2` 등)
- ⚠️ 마감일이 지났는데 아직 완료되지 않은 할 일은 "기한 지남"으로 자동 표시

### 검색 및 필터
- 🔍 할 일 제목 실시간 검색 (버튼 없이 입력 즉시 반영)
- 🗂️ 날짜 필터: 전체 / 오늘 / 이번 주 / 완료 / 미완료
- 🎨 카테고리 필터: 전체 / BK / 랩실(수업) / 프로젝트 / 스터디 / 개인
- 검색어·날짜 필터·카테고리 필터는 서로 동시에 적용 가능 (예: "이번 주 + BK 카테고리")

### 캘린더
- 🗓️ 한 달 단위 캘린더에서 할 일을 날짜별로 확인
- 시작일~마감일 기간에 걸친 할 일은 해당하는 모든 날짜 칸에 표시
- 시작일이 없는 할 일은 마감일 하루에만 표시
- 오늘 날짜 칸은 다른 날짜보다 눈에 띄게 강조
- "이전 달 / 다음 달" 버튼으로 원하는 달의 일정 확인 가능
- 캘린더의 빈 날짜 칸을 클릭하면 그 날짜가 마감일로 자동 입력된 새 할 일 등록 화면으로 이동
- 목록 보기 / 캘린더 보기 전환 탭 제공

### 데이터 저장
- 💾 브라우저 저장소(localStorage)를 이용해 서버 없이도 자동 저장
- 새로고침하거나 브라우저를 다시 열어도 등록한 할 일이 그대로 유지됨

## 🖱️ 사용 방법

1. 이 프로젝트 폴더를 내 컴퓨터로 내려받거나 복사합니다.
2. 폴더 안의 **`index.html` 파일을 더블클릭**해서 웹 브라우저(Chrome, Edge 등)로 엽니다.
   - 설치, 서버, 인터넷 연결이 전혀 필요하지 않습니다.
3. 화면 위쪽 "할 일 추가" 영역에 제목, 카테고리, 중요도(선택), 시작일(선택), 마감일을 입력하고
   **추가** 버튼을 누르면 할 일이 등록됩니다.
4. 목록에서 체크박스로 완료 표시를 하거나, **수정**/**삭제** 버튼으로 할 일을 관리할 수 있습니다.
5. 상단의 **📋 목록 보기 / 📅 캘린더 보기** 탭을 눌러 원하는 화면으로 전환할 수 있습니다.
6. 캘린더에서 날짜 칸을 클릭하면 그 날짜를 마감일로 하는 할 일을 빠르게 추가할 수 있습니다.
7. 검색창과 필터 버튼을 이용해 원하는 할 일만 골라서 볼 수 있습니다.
8. 입력한 모든 내용은 자동으로 저장되므로, 브라우저를 껐다 켜거나 새로고침해도 그대로 남아 있습니다.

> 💡 별도의 로그인/회원가입 절차가 없으며, 데이터는 사용 중인 브라우저에만 저장됩니다.
> 다른 브라우저나 다른 기기에서 열면 저장된 목록이 보이지 않을 수 있습니다.

## 🛠️ 사용한 기술

이 프로젝트는 별도의 라이브러리나 프레임워크 없이 아래 3가지 웹 표준 기술만으로 만들어졌습니다.

| 기술 | 역할 |
|------|------|
| **HTML** | 화면의 구조 (입력 폼, 목록, 캘린더 등) |
| **CSS** | 화면의 디자인 (파스텔 연두색 테마, 카드 레이아웃, 색상 구분) |
| **JavaScript (순수 자바스크립트)** | 할 일 추가/수정/삭제, 필터링, 캘린더 계산, 데이터 저장 등 모든 동작 로직 |
| **localStorage (브라우저 내장 기능)** | 서버 없이 브라우저에 할 일 데이터를 저장 |

## 📁 프로젝트 파일 구성

```
01_planner/
├── index.html      # 화면 구조 (입력 폼, 목록, 캘린더, 요약 대시보드 등)
├── style.css       # 디자인 (파스텔 연두색 테마, 카테고리/중요도 색상 등)
├── script.js       # 동작 로직 (추가/수정/삭제, 필터·검색, 캘린더 계산, 저장/불러오기)
├── PRD.md          # 프로젝트 목적, 요구사항, MVP 범위를 정리한 기획 문서
├── TASKS.md        # 기능을 단계별로 나눈 구현 작업 계획 문서
├── PROMPTS.md      # 단계별 구현을 요청할 때 사용한 프롬프트 모음 문서
└── README.md       # 지금 보고 있는 프로젝트 소개 문서
```

- **기획을 먼저 정리하고(PRD) → 단계별 계획을 세우고(TASKS) → 단계마다 구현을 요청(PROMPTS)** 하는
  순서로 이 프로젝트가 만들어졌습니다. 세 문서를 함께 보면 "왜 이렇게 만들었는지"의 흐름을 이해할 수 있습니다.
- 실제로 동작하는 프로그램은 `index.html`, `style.css`, `script.js` 세 파일입니다.
