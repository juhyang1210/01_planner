# Smart Campus Planner PRD

## 1. 프로젝트 개요

### 1.1 프로젝트명
Smart Campus Planner

### 1.2 프로젝트 목적
대학원생은 BK 사업 관련 업무, 랩실(수업) 일정, 참여 프로젝트, 스터디 모임, 개인 할 일이 동시에 얽혀 있어 일정을 한 곳에서 관리하기 어렵다. Smart Campus Planner는 대학원생이 자신의 다양한 활동 카테고리를 한 화면에서 등록·관리하고, 중요도와 마감일 기반으로 우선순위를 파악하며, 한 달 단위 캘린더로 전체 일정을 한눈에 파악할 수 있도록 돕는 개인용 일정 관리 웹앱이다.

### 1.3 배경
- 대학원생은 학업(랩실 수업), 연구비 관련 행정 업무(BK), 참여 중인 프로젝트, 스터디 모임, 개인 용무 등 성격이 다른 여러 종류의 할 일을 동시에 관리해야 한다.
- 기존 범용 To-Do 앱은 카테고리가 대학원생의 실제 활동 구조(BK/랩실/프로젝트/스터디/개인)와 맞지 않아, 항목을 분류하고 우선순위를 판단하는 데 추가적인 노력이 든다.
- 할 일과 일정이 분리되어 관리되는 경우가 많아, 한 달 전체 일정을 한눈에 조망하기 어렵다.

## 2. 대상 사용자

### 2.1 주요 사용자(Primary Persona)
- 대학원 석·박사 과정에 재학 중이며, BK 사업단 소속으로 행정 업무를 병행하는 학생
- 랩실 소속 수업(세미나, 랩미팅 등 포함)과 개인/공동 연구 프로젝트를 동시에 수행하는 학생
- 학회나 스터디 그룹에 참여하며 별도의 학습 일정을 관리해야 하는 학생

### 2.2 사용자 특성
- 하루에도 여러 카테고리의 할 일이 섞여 발생하며, 마감일과 중요도가 항목마다 다르다.
- 개인 PC/노트북 브라우저에서 주로 일정을 확인하고 관리한다.
- 별도의 회원가입·로그인 없이 빠르게 접근해 사용할 수 있는 가벼운 도구를 선호한다.
- 새로고침이나 브라우저 재접속 시에도 입력한 데이터가 유지되기를 기대한다.

## 3. 주요 요구사항

### 3.1 기능 요구사항

#### (1) 할 일 추가
- 사용자는 제목(내용)을 입력하여 새로운 할 일을 추가할 수 있다.

#### (2) 카테고리 설정
- 각 할 일은 다음 5개 카테고리 중 하나로 분류된다: BK, 랩실(수업), 프로젝트, 스터디, 개인
- 카테고리별로 시각적 구분(색상 등)이 가능해야 한다.

#### (3) 중요도 설정
- 각 할 일은 상 / 중 / 하 3단계의 중요도를 가진다.
- 중요도에 따라 목록에서 우선순위를 구분해 표시할 수 있어야 한다.

#### (4) 시작일과 마감일 지정
- 각 할 일은 시작일과 마감일을 지정할 수 있다.
- 지정된 기간은 캘린더 표시와 연동된다.

#### (5) 완료 체크 및 삭제
- 사용자는 할 일을 완료 상태로 체크/해제할 수 있다.
- 사용자는 더 이상 필요 없는 할 일을 삭제할 수 있다.

#### (6) 전체 완료율 표시
- 전체 할 일 대비 완료된 할 일의 비율을 계산하여 표시한다.
- 완료율은 할 일이 추가/삭제/완료 상태 변경될 때마다 실시간으로 갱신된다.

#### (7) 데이터 유지(로컬 저장)
- 새로고침하거나 브라우저를 다시 열어도 등록된 할 일 데이터가 유지되어야 한다.
- 별도의 서버/로그인 없이 브라우저 로컬 저장소 기반으로 데이터를 보존한다.

#### (8) 한 달 캘린더 뷰
- 월 단위 캘린더 형태로 할 일을 한눈에 확인할 수 있다.
- 각 날짜 셀에는 해당 날짜(시작일~마감일 범위 포함)에 해당하는 할 일이 표시된다.
- 카테고리별 색상 구분을 통해 캘린더에서도 카테고리를 식별할 수 있어야 한다.
- 월 이동(이전 달/다음 달) 기능을 제공한다.

### 3.2 비기능 요구사항
- 별도의 회원가입/로그인 절차 없이 바로 사용 가능해야 한다.
- 반응 속도가 빠르고, 조작이 직관적이어야 한다(입력~반영까지의 지연 최소화).
- 최신 웹 브라우저(Chrome 등)에서 정상적으로 동작해야 한다.
- 데이터 유실 방지를 위해 입력 즉시 저장이 이루어져야 한다.

## 4. MVP 범위

### 4.1 MVP에 포함되는 기능
1. 할 일 추가 (제목, 카테고리, 중요도, 시작일, 마감일 입력)
2. 카테고리 선택: BK / 랩실(수업) / 프로젝트 / 스터디 / 개인
3. 중요도 선택: 상 / 중 / 하
4. 할 일 목록에서 완료 체크(토글) 및 삭제
5. 전체 할 일 대비 완료율(%) 표시
6. 브라우저 로컬 저장소를 이용한 데이터 저장 및 새로고침 후 유지
7. 한 달 단위 캘린더 화면에서 날짜별 할 일 표시 및 월 이동

### 4.2 MVP 범위 밖(추후 고려 사항)
- 회원가입/로그인 및 다중 사용자 계정 관리
- 서버/클라우드 기반 데이터 저장 및 기기 간 동기화
- 할 일 수정(내용 변경) 기능의 세부 UI/UX 고도화
- 알림/리마인더 기능
- 카테고리 커스터마이징(사용자 정의 카테고리 추가)
- 검색 및 필터링, 정렬 옵션 고도화
- 통계/리포트(주간·월간 완료율 추이 등)
- 모바일 전용 UI 최적화

## 5. 성공 지표(참고)
- 새로고침 후 데이터 유지율 100% (저장 실패 없음)
- 할 일 추가부터 목록/캘린더 반영까지 지연 없이 즉시 표시
- 카테고리·중요도·완료 여부에 따라 목록 및 캘린더에서 시각적으로 구분 가능
